ADDITIONAL MANAGEMENT

When you need additional management

Restart or recover the service directly. Open advanced management only when you need backup, restore, previous-version transfer, external access, or removal.

Advanced package management Backup · restore · transfer · HTTPS · removal

Encrypted backup

Pauses three volumes and local state, then protects them with AES-256-CTR and HMAC-SHA256. The passphrase is not stored and must be kept separately.

Restore backup

If current state exists, PF07 creates a pre-restore backup, stops the current runtime, and replaces PF07 volumes only.

Bring forward a previous release

The package checks both release identities, safely stops the previous runtime, and continues the same store identity and data in this release.

HTTPS tunnel

Enter ENABLE PF07 TUNNEL to start and DISABLE PF07 TUNNEL to stop. Only storefront and WordPress administrator routes are exposed; the local store remains available after the tunnel stops.

Remove runtime resources

Extracted package files remain. Preserve reconnects the same state on a later start; remove creates new local state on a later start. Create any needed encrypted backup first.
