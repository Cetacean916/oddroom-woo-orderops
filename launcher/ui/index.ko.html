01

운영 방식

별도 계정 연결이 없는 데모 운영과, 보호된 외부 서비스 연결 운영 중에서 선택합니다. 방식을 바꿔도 같은 주문과 설정을 이어갑니다.

02

상점과 주문 관리

고객용 상점과 운영자용 주문 관리 도구를 각각 엽니다. 관리자 계정은 이 배포 파일 안에서 안전하게 생성됩니다.

03

데모 주문 설정

다음 주문이 정상 완료될지, 재시도나 관리자 확인이 필요할지 선택합니다. 결과와 복구 과정은 주문 관리에서 확인합니다.

04

서비스 멈추기

서비스를 멈춰도 주문과 설정은 그대로 보존됩니다. 다시 시작하면 같은 상태에서 이어집니다.

DEMO DATA CONTROL

데모 상태와 초기화

선택한 상태와 초기화 작업은 패키지가 소유한 합성 데모 데이터에만 적용됩니다. 외부 CRM·Slack·결제 서비스는 호출하지 않습니다.

적용 후 상점에서 새 합성 주문을 만들면 선택한 결과가 작업자 처리 경로에 반영됩니다.

정확히 RESET PF07 DEMO를 입력해야 합니다. 관리자 계정·카탈로그·저장된 서비스 데이터는 보존됩니다.

ADDITIONAL MANAGEMENT

추가 관리가 필요할 때

서비스 다시 시작과 복구는 바로 실행할 수 있습니다. 백업, 복원, 이전 버전 가져오기, 외부 접속, 제거는 필요할 때만 펼쳐보세요.

고급 패키지 관리 백업 · 복원 · 상태 가져오기 · HTTPS · 제거

암호화 백업

세 볼륨과 로컬 상태를 일시 정지한 뒤 AES-256-CTR과 HMAC-SHA256으로 보호합니다. passphrase는 저장하지 않으므로 별도로 보관해야 합니다.

백업 복원

현재 상태가 있으면 복원 전 백업을 먼저 만들고, 기존 런타임을 중지한 뒤 PF07 볼륨만 교체합니다.

이전 버전 상태 가져오기

두 패키지의 신원을 확인하고 이전 런타임을 안전하게 중지한 뒤 같은 상점 식별자와 데이터를 새 패키지에서 이어갑니다.

HTTPS 터널

켜려면 ENABLE PF07 TUNNEL, 끄려면 DISABLE PF07 TUNNEL을 각 입력란에 적으세요. 상점과 WordPress 관리자 경로만 공개하며, 터널을 중지해도 로컬 상점은 계속 동작합니다.

런타임 자원 정리

추출한 패키지 파일은 남습니다. 보존을 선택하면 다음 시작 때 같은 상태를 다시 연결하고, 제거를 선택하면 다음 시작 때 새 로컬 상태를 만듭니다. 필요한 암호화 백업을 먼저 만드세요.
